# MQ Creator · plugins oficiais

Site público (GitHub Pages) com os plugins oficiais do MQ Creator: MQ Paint, MQ 3D Blocks, MQ Forms e Task Generator.

- `index.json` — catálogo que o MQ Creator lê em «Plugins…» (id, versão, ficheiro, tamanho, sha256).
- `plugins/<Pasta>-<versão>.zip` — cada versão; `plugins/<Pasta>.zip` — a mais recente.

O MQ Creator só instala um pacote se o sha256 bater com o do catálogo. Gerado por `tools/plugins_site.py`
no repositório do MQ Creator (não editar à mão).
